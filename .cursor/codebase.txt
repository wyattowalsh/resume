This repository is a Vike + React resume system for Wyatt Walsh.

Core architecture:

- Canonical resume content lives in `assets/data/resume.json`.
- Variant overlays live in `assets/data/variants/{site,full,single}.json`.
- Runtime data loading and variant resolution live in `src/lib/resume-data.ts`.
- Human-facing routes are `/` for the web resume, `/full` for the 2-page artifact view, and `/single` for the 1-page artifact view.
- Shared rendering components live in `src/components/`.
- PDF, DOCX, and PNG generation flows are implemented under `src/scripts/`.
- Generated artifacts are written to `assets/outputs/`; public downloads are synced to `public/downloads/`.

Primary commands:

- `pnpm dev` starts the Vike development server.
- `pnpm build` builds the site.
- `pnpm generate:resume` regenerates PDF, DOCX, and PNG artifacts.
- `pnpm check:artifacts` verifies generated and public artifacts, extracted text, hashes, and wording expectations.
- `pnpm sync:public-downloads` copies generated PDF and DOCX artifacts into `public/downloads/`.

Important wording context:

- The 1-page PDF is visually compressed and may suppress work role summaries.
- The DOCX exports intentionally retain ATS-oriented semantic content, including basics summary, role summaries, and project highlights.
- NBA Basketball Database wording should distinguish the public Kaggle dataset/repo frozen at the 2023-07-06 update from the newer in-development `nbadb` rebuild.
