## Dev Docs Tech Stack

This documentation site is built as a separate Next.js application within the main monorepo. It has its own set of dependencies, which are a subset of the main project's stack, tailored specifically for delivering a fast and beautiful documentation experience.

| Dependency | Description | Homepage | GitHub | Usage Notes |
| :--- | :--- | :--- | :--- | :--- |
| **Framework & UI** |
| `Next.js` | The React Framework for Production. | [nextjs.org](https://nextjs.org) | [vercel/next.js](https://github.com/vercel/next.js) | Core framework for the docs application. |
| `Fumadocs` | A beautiful documentation framework built on top of Next.js and MDX. | [fumadocs.dev](https://fumadocs.dev) | [fuma-nama/fumadocs](https://github.com/fuma-nama/fumadocs) | `fumadocs-core`, `fumadocs-mdx`, `fumadocs-ui`. The primary tool for building this site. |
| `Tailwind CSS` | A utility-first CSS framework for rapidly building custom user interfaces. | [tailwindcss.com](https://tailwindcss.com) | [tailwindlabs/tailwindcss](https://github.com/tailwindlabs/tailwindcss) | `tailwindcss`, `tailwind-merge`, `postcss`. For all styling. |
| `Lucide` | A simply beautiful and consistent icon toolkit. | [lucide.dev](https://lucide.dev) | [lucide-icons/lucide](https://github.com/lucide-icons/lucide) | `lucide-react`. Used for icons. |
| **Utilities** |
| `clsx` | A tiny utility for constructing `className` strings conditionally. | [github.com/lukeed/clsx](https://github.com/lukeed/clsx) | [lukeed/clsx](https://github.com/lukeed/clsx) | Utility for managing class names. |
| `class-variance-authority` | A library for creating type-safe and composable UI components. | [cva.style](https://cva.style) | [joe-bell/cva](https://github.com/joe-bell/cva) | Used for creating variant-based components like buttons. |
